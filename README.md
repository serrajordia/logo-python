# Logo em Python

Um pequeno interpretador da linguagem Logo (comandos em português) para
ensinar matemática desenhando com uma tartaruga. Sem dependências além do
Python padrão (usa o módulo `turtle`).

## Início rápido

```
python logo.py                              # modo interativo
python logo.py exemplos\01_quadrado.logo     # roda um exemplo pronto
```

Veja o **[TUTORIAL.md](TUTORIAL.md)** para uma introdução passo a passo,
pensada para estudar com uma criança (ângulos, polígonos, multiplicação,
sequências e um pouco de recursão).

## Arquivos

- [`logo.py`](logo.py) — o interpretador.
- [`exemplos/`](exemplos) — programas prontos (quadrado, polígonos,
  estrela, espiral, tabuada em gráfico de barras, árvore fractal).
- [`TUTORIAL.md`](TUTORIAL.md) — o tutorial.
